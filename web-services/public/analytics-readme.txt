Stilloak Web analytics activation

Google Analytics is loaded only after the visitor grants Analytics consent in the cookie settings.

Required Vercel environment variable for web-studio:
VITE_GA_MEASUREMENT_ID=G-XXXXXXXXXX

Lead attribution is captured separately from Google Analytics and is stored with submitted Web orders:
- source
- medium
- campaign
- content
- term
- referrer
- landingPage
- gclid
- fbclid
